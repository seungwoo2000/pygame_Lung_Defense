호흡기 건강의 핵심 지표인 **산소포화도(SpO2)** 를 게임으로 시각화한 폐 방어 슈팅게임입니다.  
폐를 위협하는 요소들(먼지·담배·고지방 식품)을 적으로 표현하고, 플레이어가 폐포 병사를 조종해  
이를 직접 격추하면서 호흡기 건강 지식을 자연스럽게 습득할 수 있도록 기획했습니다.

## 🎮 게임 방법

### 조작법

| 키 | 동작 |
|----|------|
| `← →` 방향키 | 폐포 병사 대열 좌우 이동 |
| `Space` | 총알 발사 (모든 병사 위치에서 동시 발사) |
| 마우스 클릭 | 버튼 조작 (시작 / 다시하기 / 종료) |

### 승패 조건

| 결과 | 조건 |
|------|------|
| ✅ **SUCCESS** | 60초 후 SpO2 **90% 이상** 유지 |
| ❌ **GAME OVER** | SpO2 **0% 도달** / 병사 **전멸** / 적이 **화면 바닥 도달** |

> SpO2는 시간이 지날수록 초당 5%씩 자동 감소합니다.  
> 적을 처치하거나 아이템을 획득해 SpO2를 회복하세요!

## 👾 등장 오브젝트

### 적군 — 화면 위에서 낙하

| 종류 | 등장 시점 | 기본 체력 | 처치 점수 | SpO2 회복 |
|------|-----------|-----------|-----------|-----------|
| 💨 먼지 | 시작 즉시 | 1 | +1점 | +1% |
| 🍔 고지방/고당분 | 10초 후 | 2 | +6점 | +3% |
| 🚬 담배 | 15초 후 | 4 | +10점 | +5% |
| 👾 보스 | 20초 후 (15초 간격, 최대 3회) | 100 / 200 / 300 | +100점 | +10% |

> ⚠️ 경과 시간에 따라 적의 체력이 자동으로 증가합니다 (난이도 스케일링)

### 아이템 — 화면 오른쪽에서 낙하

| 아이템 | 효과 |
|--------|------|
| 🥦 브로콜리 | 폐포 병사 1명 추가 (최대 30명) |

### 필살기

| 종류 | 발동 시각 | 효과 |
|------|-----------|------|
| 💊 네불라이저 | 18초 / 28초 / 45초 | 화면의 모든 적 체력 -50 |

| 언어 | Python 3.x |

### 주요 구현 포인트

**① 해상도 자동 대응**  
모니터 크기를 감지해 게임 창 비율을 자동 계산합니다.  
클릭 좌표를 `scale_ratio`로 보정해 어떤 화면에서도 동일하게 작동합니다.
```python
scale_ratio = min(monitor_w / BASE_WIDTH, monitor_h / BASE_HEIGHT) * 0.8
```

**② 상태 머신 기반 화면 전환**  
화면 전환을 상태 상수(0~3)로 관리해 충돌 없이 명확하게 분기합니다.
```
시작화면(0) → 스토리 인트로(1) → 준비화면(2) → 본게임(3)
```

**③ 시간 기반 난이도 스케일링**  
경과 시간에 비례해 적 체력이 자동으로 증가합니다.
```python
scaled_hp = BASE_HP + int(경과_시간(초) * ENEMY_HP_SCALE_PER_SEC)
```

**④ 리소스 누락 방어 처리**  
이미지·사운드 파일이 없어도 게임이 튕기지 않도록 모든 로드 함수에 예외 처리를 적용했습니다.
```python
def load_sound(path):
    try:    return pygame.mixer.Sound(path)
    except: return None
```

**⑤ 겹침 방지 스폰 시스템**  
새 오브젝트 생성 시 기존 오브젝트와 겹치지 않는 좌표를 최대 100회 탐색합니다.

## ⚙ 밸런스 조정 가이드

`game.py` 상단의 상수 값만 수정하면 게임 밸런스를 바로 조절할 수 있습니다.

| 상수명 | 기본값 | 설명 |
|--------|--------|------|
| `SPO2_DECAY_PER_SEC` | `5` | 초당 SpO2 감소량 (줄이면 쉬워짐) |
| `TIME_LIMIT` | `60` | 게임 제한 시간(초) |
| `ENEMY_HP_SCALE_PER_SEC` | `0.15` | 시간당 적 체력 증가량 |
| `BOSS_HP_LIST` | `[100, 200, 300]` | 보스 1~3차 체력 |
| `NEBULIZER_SPAWN_TIMES` | `[18, 28, 45]` | 필살기 등장 시각(초) |
| `BROCCOLI_MAX_STACK` | `30` | 최대 병사 수 |
